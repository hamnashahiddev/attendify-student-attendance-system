## [1.0.0] - 2026-11-22

### Added
- Initial Django-based Student Attendance Management System.
- Authentication system with role-based access for staff, teachers, and students.
- Separate dashboards for staff and students.
- Student management with profile, detail, add, edit, and delete functionality.
- Teacher management with profile, detail, add, edit, and delete functionality.
- Classroom management.
- Department management.
- Subject management.
- Attendance marking system.
- Attendance history tracking.
- Attendance report generation.
- CSV export for attendance records and reports.
- Timetable management and scheduling.
- Announcements system.
- Notification center with read and mark-all-as-read functionality.
- User profile management.
- Password change functionality.
- Admin panel integration.
- Site settings management.
- Custom error pages (403, 404, and 500).
- Demo data seeding command for testing.
- Initial project structure, templates, styling, and documentation.

### Tech Stack
- Python
- Django
- SQLite
- HTML
- CSS
